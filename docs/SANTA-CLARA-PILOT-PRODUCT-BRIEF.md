# Beebizy Studio for Santa Clara University

## Pilot product brief

**Prepared:** September 12, 2026  
**Pilot focus:** Santa Clara University event operations  
**Demo target:** October 7 or October 8, 2026

## Product goal

Give the Santa Clara team one simple workspace that replaces the parts of spreadsheets and HubSpot that make event planning and event-day operations tedious. The pilot is intentionally narrow. It centers the work the team performs repeatedly and removes unrelated choices from their view.

The Santa Clara dashboard is labeled **Customized for Santa Clara University**.

## Focused dashboard

The dashboard opens the team's current event and provides direct access to seven work areas:

1. **Run of show** - Build and edit the minute-by-minute event schedule, duration, description, and responsible person.
2. **Checklist** - Track line-item tasks, due dates, completion, and the person assigned to each task.
3. **Budget** - Track planned and actual amounts for each expense or revenue line item.
4. **Floorplan** - Start with a blank space and drag in tables, chairs, trees, entrances, stages, booths, bars, dance floors, and AV positions.
5. **Registrations** - Add or import guests and organize them by guest type and organization. The default guest types include Investor, Company, and General.
6. **Check-in** - Search the guest list, record arrivals, manage entry stations, register walk-ins, print the guest list, and print individual badges.
7. **Volunteers** - Assign volunteers to roles and time slots, track confirmation and arrival status, and keep shift notes.

The main navigation contains only Dashboard, Events, and Import spreadsheet. Account settings and sign-out remain available in the sidebar footer.

## Spreadsheet and Google Sheets import

The team can begin with the planning tools it already uses:

- Upload a multi-sheet Excel file or CSV file.
- Paste a public Google Sheets link.
- Review the event and every recognized record before saving.
- Import event details, checklist tasks and owners, run-of-show entries, budget line items, guests, guest types, organizations, services, and vendors.
- See a warning naming any sheet the importer did not recognize, so information is not silently dropped.

A separate guest-list import supports CSV exports from HubSpot and Google Sheets. It recognizes common name, email, company, organization, guest type, registration type, and lifecycle-stage columns.

## Simplified registration and check-in workflow

1. Import the guest list or add registrations directly to the event.
2. Review guests by type, such as Investor, Company, and General, and by organization.
3. Mark registrations confirmed or pending before the event.
4. Create entry stations or lanes and assign a lead to each station.
5. On event day, search by name, email, guest type, organization, or station.
6. Check in a guest with one action, or confirm and check in a pending guest.
7. Add a walk-in without leaving the check-in screen.
8. Print the live guest list or an individual badge at the desk.
9. Review checked-in guests, guests still expected, and no-shows.

## Volunteer workflow

For every volunteer, the team can record:

- Name and contact details
- Assigned role
- Start and end time
- Scheduled, confirmed, checked-in, completed, or cancelled status
- Shift-specific notes

The volunteer schedule is event-specific so each event has a clear operating roster.

## Features hidden for this pilot

The following existing Beebizy areas remain in the codebase but are not shown to Santa Clara pilot accounts:

- Raffle
- Fundraising and sponsorships
- Silent auction
- Live auction
- Tickets
- Menu
- Vendor management and messages
- RFPs and deposits
- Inspiration boards
- Contingency planning
- Portfolio reporting and historical data
- General template library and broad planning navigation

This is a reversible customer profile, not a deletion. Other Beebizy workspaces retain the full product, and the Santa Clara profile can be changed without rebuilding removed features.

## Pilot acceptance criteria

The focused pilot is ready when the Santa Clara team can:

- Sign in and immediately see the Santa Clara customization label.
- See only the focused pilot navigation and event work areas.
- Import its existing planning spreadsheet without losing guest type or organization.
- Edit imported run-of-show, checklist, budget, and registration data.
- Assign checklist owners and volunteer shifts.
- Build and save a floorplan containing fixed site features and movable furniture.
- Segment and filter registrations by Investor, Company, General, and organization.
- Run check-in for a large guest list without rendering all records at once.
- Register a walk-in, undo a check-in, print a guest list, and print a badge.
- Submit product feedback from inside the signed-in product.

## Feedback and success measures

During the pilot, product decisions will prioritize Santa Clara's observed workflow. Feedback should be reviewed against these measures:

- Time required to import and prepare one event
- Number of spreadsheet corrections required after import
- Time required to find and check in one guest
- Accuracy of guest type and organization reporting
- Number of unassigned checklist tasks before event day
- Volunteer shift coverage and clarity
- Difference between registrations, attendance, and no-shows
- Whether the team can operate the event without returning to a parallel spreadsheet

## Pre-meeting questions

1. Which spreadsheet tabs and column names are present in the current full event file?
2. Does Company mean company representative, sponsor, or a separate guest category?
3. Which physical site features must be fixed on the floorplan before the team places furniture?
4. What badge size and printer model will be used at check-in?
5. How many check-in stations and devices are expected for Demo Day?
6. Who should be selectable as checklist owners and volunteer leads?
7. Should imported registrations default to confirmed, pending, or preserve a status column?
