Where the product stands

Beebizy Studio now covers the five workflows identified as P0 / V1 Core. Together, they give a small team one place to plan the event, coordinate the day, manage financials, organize the venue, and retain the decisions made along the way.

This is an important shift from a collection of planning tools to an event system of record. Information entered by signed-in users is saved to a workspace and remains available across sessions. The public demo stays separate, so prospects can explore the experience without touching partner data.

Completion means: the five agreed workflows are present, usable, persistent for authenticated teams, and verified on the live product. Adoption will be confirmed through real-event use by Eleventy Milano and Campbell Hall.

Why this release matters

The value of V1 is not simply that each feature exists. The workflows feed a shared history, creating a useful record of how events are planned and delivered. As Beebizy is used across more events, this gives the team a reliable base for better reporting and, later, more informed suggestions.

The five completed workflows

1Run-of-show builder

Teams can build the operational timeline for an event, including cue times, duration, ownership, descriptions, and display order. The schedule respects the event time zone and can be updated as plans change.

  • Create, edit, reorder, and delete cues
  • Assign a responsible owner
  • Retain timing and ownership changes in planning history

2Multi-location calendar

Teams can see upcoming events in list or calendar view, with each event connected to a saved venue rather than a loose text field. Events can be filtered to one venue or viewed across all locations.

  • Saved venue records
  • Venue and event time visible on calendar entries
  • Location filtering, including events without an assigned venue

3Budget management

Each event includes a working budget with planned and actual amounts. Teams can separate revenue from expenses, organize lines by category, and see variances at event and portfolio level.

  • Expense and revenue lines
  • Estimated and actual amounts
  • Automatic variance calculations and portfolio summaries

4Historical data tracking

Beebizy records important planning changes as structured history. Each entry identifies the workspace, event, person, action, resource, time, and the values before and after the change.

  • Event, schedule, budget, vendor, checklist, ticketing, fundraising, and floorplan activity
  • Human-readable summaries for the planning timeline
  • Structured data for reporting across future events

5Floorplan builder

Teams can create and save venue layouts using common event elements. Positions are stored proportionally so the layout remains readable across different screen sizes.

  • Round and long tables, stages, bars, entrances, dance floors, booths, and AV areas
  • Labels, seat counts, and saved positions
  • Venue, capacity, and guest-count context retained for future layout guidance

  5. Feedback is captured against the agreed test cases.
  6. Any blocking usability or data-integrity issues are resolved.
